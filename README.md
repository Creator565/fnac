# Five Night At Calculator's

This is a recreation of the original five night at freddy's made with fx-sdk for fx-G9860 series calculators.
It implements everything from fnaf 1 except:
- All eastereggs
- Death waits (you gets jumpscared immediately after any animatronics enter your office)
- Blackout countdown

It's also my first c++(or c for that matter) project and it is by all means **ATROCIOUS** and wwill make your eyes bleed if you look at the code
